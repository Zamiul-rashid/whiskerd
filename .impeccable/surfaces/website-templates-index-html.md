# whiskerd project website (home page)

Scope: the single-page project site at https://zamiul-rashid.github.io/whiskerd/ (Zola, `website/`).
Visitor mode: Persuade. Visitor: a Linux desktop user whose 2.4 GHz mouse shows no battery level.
Job, in order: see that it does what they want, check their mouse, copy the install command.
Proof on hand: real protocol bytes, real JSON output, the evidence-levelled mouse list. Nothing else
may be claimed (no users, stars, benchmarks beyond "about 2 MB of RAM").
Constraints: /apt, /rpm, /whiskerd.asc on the same gh-pages branch must keep working; Linux only.

## Direction contract

THESIS: Every compatible mouse is a die-cut sticker you peel off a backing sheet and stick in your
top bar. Refuses the dark terminal-hero dev-tool page with a three-card feature grid.

OWN-WORLD: The page is a blue-grey sticker backing sheet (mascot body tones) with a faint printed
release-liner pattern. Content lives on white kiss-cut stickers whose outlines follow the artwork;
commands sit on white label-maker strips. Pink is rationed to battery numbers and the mascot's own
ears, tail and feet. Rounded Japanese pop display face, rounded gothic body, real mono for bytes.
Tested mice are printed full-colour stickers; expected ones are dashed kiss-cut outlines not yet
printed. Hairline crop marks register the sheet's corners.

STORY: The visitor sees their top bar with a mouse and a percentage, understands it reads the
receiver directly (shown as real bytes), finds their mouse on the sheet with an honest evidence
level, and copies one install line.

FIRST VIEWPORT: Left 57%: display headline (2–3 lines at desktop widths; Mochiy Pop One is wide), one-sentence subline, the apt install strip
with a Copy control, then text links to Fedora/Arch/source and GitHub. Right: the mascot as a large
die-cut sticker (~22rem) tilted a few degrees, overlapped at its lower left by a die-cut top-bar
sticker (dark pill: mascot icon + "74%" + "Ajazz AJ179P"). Crop marks in the corners.

FORM: Sticker Sheet, position 7 of the grounded list, seed key 69e56e79.

Signature interaction: stickers peel at one corner on hover/focus (lifting shadow + curled corner);
the hero top-bar sticker settles onto the sheet once on load. Reduced motion: static.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
