Your mouse’s battery, right in the top bar.

Many 2.4 GHz mice never tell Linux how full their battery is. whiskerd asks the USB receiver directly, read-only, and a GNOME extension shows the level in the top bar.

sudo apt install whiskerd

After adding the repository. Also for Fedora, Arch and any distro from source.

Illustration: whiskerd in the GNOME top bar, a small mouse icon and 74%.

  • About 2 MB of RAM, no CPU while idle
  • No root at runtime
  • Plug in a dongle, the mouse appears
  • Read-only: never changes a setting

Does my mouse work?

whiskerd talks to the receiver, so what counts is the dongle your mouse came with. Run lsusb to see its ID. Every mouse below says how sure we are.

Not on the sheet? Open an issue with the output of lsusb and whiskerd --probe. If the receiver speaks a protocol whiskerd knows, adding it is one line.

It reads the receiver, byte by byte

No vendor app, no guessing. These are real replies captured from the two tested mice, with the battery byte in pink.

The result is one small JSON file in RAM, $XDG_RUNTIME_DIR/whiskerd.json:

{"devices":[{"id":"248a:5b2f@3-5.1","name":"Ajazz AJ179P","kind":"mouse",
  "battery":74,"charging":false,"connected":true,"updated":1795190426}]}

The GNOME extension watches it. Other bars can read it too, or run whiskerd --output - for one JSON line per change (Waybar, polybar, eww).

Install

Ubuntu / Debian

curl -fsSL https://zamiul-rashid.github.io/whiskerd/whiskerd.asc | sudo gpg --dearmor -o /usr/share/keyrings/whiskerd.gpg
echo "deb [signed-by=/usr/share/keyrings/whiskerd.gpg] https://zamiul-rashid.github.io/whiskerd/apt stable main" | sudo tee /etc/apt/sources.list.d/whiskerd.list
sudo apt update && sudo apt install whiskerd

Fedora

sudo curl -fsSL -o /etc/yum.repos.d/whiskerd.repo https://zamiul-rashid.github.io/whiskerd/rpm/whiskerd.repo
sudo dnf install whiskerd

Arch Linux

Download whiskerd-*.pkg.tar.zst from the releases, then:

sudo pacman -U whiskerd-*.pkg.tar.zst

Or build it from packaging/arch/PKGBUILD with makepkg -si.

From source, any distro

Needs Rust. Asks for sudo once, for the udev rule.

git clone https://github.com/Zamiul-rashid/whiskerd && cd whiskerd
./install.sh

Then

  1. Start the daemon: systemctl --user restart whiskerd. It starts at every login after that.
  2. On GNOME, log out and back in once, then run gnome-extensions enable whiskerd@zamiul-rashid.
  3. Check what it finds: whiskerd --probe.
